# 发布清单(发一次版照着走一遍)

决策不在这里(为什么发、能不能发、不做 Pay Skill 的理由,见主仓库
`Geo-Analytics/docs/16-skill对外发布.md`)。这里只有**动作**。

## 一、打包

```bash
tools/pack.sh                    # → $TMPDIR/vtag-skill-dist/vtag-geo-analytics-<version>.zip
VTAG_DIST=~/somewhere tools/pack.sh
```

**产物打在仓库外面**,`VTAG_DIST` 指到仓库里会直接报错退出。不是"打进 `dist/` 再忽略掉"——
那样仓库目录里始终躺着一个 zip,传的人分不出手里这个是不是最新的,git 忽略它也拦不住
有人把它拖进上传框。

打完脚本自校验三件事,任一不过就非零退出:根目录有 `SKILL.md` / ≤ 10 MB / ≤ 200 文件。

## 二、上传时的两个坑

两个都**只在上传那一刻暴露**,本地怎么读都是对的。

1. **传 zip,不要选文件夹。** 文件夹上传会把目录拍平(平台显示「已选择 4 个文件」且没有
   层级),`SKILL.md` 里指向 `references/`、`scripts/` 的路径当场不成立;
2. **`description` 必须是单行。** 用 YAML 折叠块 `>-` 时,平台抓到的描述就是 `>-`
   这两个字符本身。已改成单行双引号,**别改回去**。

## 三、表单字段速查

⚠️ **值以 `vtag-geo-analytics/SKILL.md` 的 frontmatter 为准**,下表是抄件。
要改就改 frontmatter,别改这张表。

| 字段 | 取自 | 备注 |
|---|---|---|
| Slug | `name` | `vtag-geo-analytics`,**提交后不可改** |
| 显示名称 | 手填 | `GEO Analytics · AI 引擎可见度` |
| 图标 | 官网 logo | `Geo-Analytics/client/home/logo.svg` 导 512×512 PNG,透明底 |
| 描述 | `description` | 上传后点「使用此描述」即可;要手填就复制下面那段 |
| 分类 | 手选 | 数据分析 > 营销/增长/SEO > 开发者工具,选 2~3 个 |
| 版本号 | `version` | 与 frontmatter 逐字符一致 |
| 变更说明 | [CHANGELOG](CHANGELOG.md) | 粘对应版本那一段 |
| 计费 | — | **免费**(免费模式无需商户入驻) |

上传后平台会自动抓 frontmatter 里的这一段,正常情况下点「使用此描述」就行,

## 四、提交前自检

- [ ] `tools/gen_endpoints.py --check` 通过(端点表与后端同步);
- [ ] 传的是刚打的 zip,不是上一版留在临时目录里的;
- [ ] 上传后文件列表里 `SKILL.md` 在根,`scripts/`、`references/` 层级还在;
- [ ] 「检测到描述」显示整段中文,**不是 `>-`**;
- [ ] Slug、版本号与 frontmatter 逐字符一致;
- [ ] 包里和描述里没有 token、密钥、内网地址(平台安全审核查密钥泄露);
- [ ] 主仓库 `docs/16` §六那五条阻塞项**已经清掉** —— 生产 `/api/oauth/*` 还 404 的话,
      装上就走不完授权。

## 五、发布之后

- 平台建议补 **3 个效果案例**(发布成功页 →「对话式补充案例」),写法见 `docs/16` §五;
- 端点有任何变化 → 跑生成器 → bump `version` → 记 CHANGELOG → 重发一版。
  **发布过的端点只加不改**:装出去的是快照,改契约等于让已装用户静默出错。
