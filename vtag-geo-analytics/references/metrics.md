# 指标公式与口径红线

这份文件是 SKILL.md 里那两节的展开版。**公式照抄产品文档,不在这里重新定义**——
同一个指标在控制台、在 API、在这个 skill 里必须是同一个数,因为它们本来就是同一份 SQL。

## 一、六指标(over `engine_probe` / `probe_events` 事件流)

| 指标 | 聚合公式 |
|---|---|
| 整体露出率 | `count(brand_hit) / count(is_valid)`,仅 `scene_type ∉ {brand, compare}` |
| TOP1露出率 | `count(brand_rank=1) / count(brand_hit)`(品类词口径) |
| TOP3露出率 | `count(brand_rank≤3) / count(brand_hit)` |
| 内容中正率 | `(1 − count(is_negative ∧ brand_hit) / count(brand_hit)) ×100` |
| 文章引用率 | `count(cites_owned) / count(is_valid)` |
| 品牌声量度 | `count(brand_hit) / (count(brand_hit) + Σcompetitor_count)` |

**能出与不能出**:前三个 + 文章引用率由机械判定(字符串与域名匹配)得出,一直有;
内容中正率与品牌声量度依赖 `is_negative` / `competitor_count` 这两个语义字段,
**没判定就是 `null`,不是 0,也不是「暂无」后面跟一个数**。

`/engines` 返回的 `citation_rate` / `exposure_rate` / `top3_rate` 就是上表前几项;
`probes=0`(本期没采过)时它们是 `null`——**没采过就没有率,不出 0%**。

## 二、指标名不自创

引擎侧只用上面这些名字:**文章引用率 / 整体露出率 / TOP1 露出率 / TOP3 露出率 /
内容中正率 / 品牌声量度**。

不叫「曝光」「引流」「效果」「触达」。它测的是「引擎的回答里出现了你」——
一次被引对应多少真人看到,我们不知道,就不装知道。

## 三、口径红线(原文)

1. **两列各讲各的事实,不 join、不暗示因果。** 禁止任何「引擎侧被引 N 次 →
   带来了 M 访客」式的换算、连线、箭头;
2. **DeepSeek 站点侧栏写「测不到」而不是 0**——0 是测过没有,测不到是没有测量手段,
   混淆这两者等于向客户撒谎;
3. **引擎侧指标只用既定的名字**(文章引用率/露出率),不叫「曝光」「引流」「效果」;
4. **「来源未知」桶保持原样**,不因为引擎侧有了 DeepSeek 数据就把未知流量归给它。

### 为什么第 1 条这么硬

因为它是拿生产数据换来的结论,不是谨慎措辞:AI 引擎引用的是发在第三方平台上的文章,
访客从那些页面点过来时,中间那一跳是**公开网页**,来源信息在那里就丢了。
「被引」与「来到站点」之间没有可用的连接键——不是我们还没实现,是这条路上没有东西可实现。

所以:两套指标**分别呈现**,报表和回答都不得在两者之间暗示因果。

### 站点侧的四档来源(`/acquisition?dimension=engine` 返回的 `key` 原值)

API 返回的是**原值**,不是控制台上的中文标签。四档含义不同,**不要合并、不要改写**:

| `key` 原值 | 含义 | 怎么说给用户听 |
|---|---|---|
| 引擎码(见下表) | 有 referrer 或注入参数,判得出来 | 该引擎带来的会话 |
| `(external)` | 从外站跳来,但来源被抹掉了 | **来源未知**,不是「非 AI」 |
| `(direct)` | 地址栏 / 书签,真·直接访问 | 直接访问 |
| `""`(空串) | 连 `nav_site` 信号都没有(站点没配、浏览器不支持、历史数据) | 无法判定 |

`(external)` 是 AI 归因的**候选池上界**,不是 AI 流量本身——DeepSeek 这类抹来源的引擎落这里,
App 内嵌浏览器、任何 `rel="noreferrer"` 链接同样落这里。**不许把这一档说成某个引擎的流量。**

引擎码取值(`/engines` 的 `engine` 列同此)——**照原样读,不要自己音译或缩写**:

    doubao(豆包) deepseek(DeepSeek) wenxin(文心) qwen(通义千问)
    yuanbao(腾讯元宝) kimi(Kimi) chatgpt(ChatGPT) perplexity(Perplexity) gemini(Gemini)

其余维度里的占位值同理照原样读:`(not set)` = 客户没报这个参数,`(unknown)` = 判不出来,
两个都**不是 0、不是「其他」**。

## 四、其余口径提醒

- **时长类指标看中位数**:平均值受长尾扭曲(挂着不动的标签页),`/engagement` 两个都返回,
  要给用户看的是 `median_engagement_sec`;
- **转化金额按币种分列,跨币种不相加**;客户没报币种的落 `currency=""` 单列一档,
  **不默认成人民币**;
- **爬虫流量已从常规报表排除**,想看爬虫调 `/bots`,两边不重叠;
- **IVT(无效流量)是数据质量账,不是安全账**:打标不拦截,每条可复核到规则编号;
- **不合成评分**:不要把这些指标加权成「GEO 健康分」「AI 可见度总分」。
  合成分掩盖口径,用户没法追到哪个数出了问题。
